# Design of Digital Systems: VHDL Labs

VHDL lab projects from Design of Digital Systems, implemented and verified on FPGA.

## Projects

### ALU
A 6-bit combinational ALU combining logic, add/subtract, multiply, and shift operations behind a single opcode select.

### Register File
A structural 8×4 register file with decoder-driven writes and mux-based reads, supporting one read/write per clock cycle.

---

Each project folder contains its own VHDL source and README with a full breakdown of the module hierarchy and design.
